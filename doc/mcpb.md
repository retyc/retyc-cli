# MCPB bundle — Claude Desktop extension

Each release ships `retyc-<version>.mcpb`, a one-click installable
[MCPB bundle](https://github.com/modelcontextprotocol/mcpb) for Claude Desktop
(and any other MCPB-aware client).

## Install

1. Download `retyc-<version>.mcpb` from the
   [latest release](https://github.com/retyc/retyc-cli/releases/latest).
2. Open it with Claude Desktop (double-click, or Settings → Extensions → Install).
3. Fill in the settings form:
   - **Encryption Key Passphrase** (required) — your Retyc private-key passphrase.
   - **Retyc Token** (optional) — offline token to skip the interactive login;
     leave empty to log in via the `auth_login_start` tool from the chat.

Both values are stored in the OS keychain (`sensitive: true` in the manifest).

## What's inside

An `.mcpb` is a plain ZIP with `manifest.json` at the root:

```
retyc-<version>.mcpb
├── manifest.json             # generated by `retyc mcp manifest`
├── icon.png                  # mcpb/icon.png (512×512)
└── server/
    ├── retyc-darwin          # macOS universal binary (arm64 + amd64)
    ├── retyc-linux           # Linux amd64
    └── retyc-windows.exe     # Windows amd64
```

One bundle covers all platforms: MCPB platform selection is **per OS only**
(`server.mcp_config.platform_overrides` keyed on `darwin`/`win32`/`linux`, no
architecture dimension), so the macOS binary must be a universal binary
(built by goreleaser `universal_binaries`).

## Manifest generation — the Go code is the source of truth

`retyc mcp manifest` prints the complete `manifest.json`:

- static metadata comes from `cmd/mcpb_manifest_base.json` (embedded via `go:embed`);
- `version` is the build-time version (ldflags), leading `v` stripped;
- `tools` is read from the live MCP tool registry (same registration as `mcp serve`).

Manifest version ≡ binary version by construction; the tool list can never drift
from the code. To inspect just the tools: `retyc mcp manifest | jq .tools`.

## Build

```sh
make mcpb        # goreleaser snapshot + scripts/build-mcpb.sh → dist/retyc-<version>.mcpb
```

Requirements: `goreleaser`, `jq`, `zip`. **No Node.js** — the bundle is a plain
ZIP; the official `@anthropic-ai/mcpb` CLI is only used in CI for validation.

`scripts/build-mcpb.sh` locates the binaries via `dist/artifacts.json`, stages
`dist/mcpb/`, generates the manifest with the freshly built binary, and zips.

## Release CI

On `v*` tags, the `goreleaser` job of `.github/workflows/release.yml`:

1. runs goreleaser (binaries + universal binary, version injected from the tag);
2. `scripts/build-mcpb.sh --expect-version "${tag#v}"` — **fails the release if
   the manifest version does not match the tag**;
3. validates the manifest with `npx @anthropic-ai/mcpb validate`;
4. uploads the `.mcpb` to the GitHub release.
