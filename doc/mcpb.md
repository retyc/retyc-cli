# MCPB bundle — Claude Desktop extension

Each release ships `retyc-<version>.mcpb`, a one-click [MCPB bundle](https://github.com/modelcontextprotocol/mcpb)
for Claude Desktop (and other MCPB-aware clients). It holds the binaries for macOS
(universal), Linux and Windows.

## Install

1. Download `retyc-<version>.mcpb` from the
   [latest release](https://github.com/retyc/retyc-cli/releases/latest).
2. Open it with Claude Desktop (double-click, or Settings → Extensions → Install).
3. Fill in the **Encryption Key Passphrase**, stored in the OS keychain.
4. Ask Claude to *"log me into Retyc"* and open the link it gives you.

## Build

```sh
make mcpb        # → dist/retyc-<version>.mcpb (needs goreleaser, jq, zip)
```

`manifest.json` is generated by `retyc mcp manifest` from the code itself (version and
tool list), so it never drifts from the binary. The release workflow fails if its version
does not match the tag, and validates it with `npx @anthropic-ai/mcpb validate`.

## npm package `@retyc/mcp`

`make npm npm-test` builds and checks `@retyc/mcp`, a Node launcher running `retyc mcp <args>`
(`serve` by default), and one package per platform holding the binary
(`@retyc/mcp-{linux-x64,linux-arm64,darwin-x64,darwin-arm64,win32-x64}`); npm installs only
the one matching the machine. The version comes from the tag.

The release publishes them with trusted publishing (OIDC, no npm token), pre-releases on the
`beta` dist-tag. One-time setup per package: publish a first **final** version by hand
(`npm publish --access public`; npm points `latest` at it whatever its dist-tag), then add the
trusted publisher on npmjs.com (repository `retyc/retyc-cli`, workflow `release.yml`).

If a release fails after goreleaser, re-running the job does not help (the GitHub release
assets already exist). Finish by hand from the tag with the release's `dist/`:
`scripts/build-npm.sh`, `npm publish` of each missing package (platform packages first),
`scripts/build-server-json.sh`, `mcp-publisher publish dist/server.json`.

## MCP Registry `com.retyc/mcp`

`packaging/mcp/server.json` lists the npm package and the MCPB bundle;
`scripts/build-server-json.sh` fills in the version and the bundle's URL and SHA-256. The
release publishes final releases only, authenticated by DNS on `retyc.com`. One-time setup:

```sh
openssl genpkey -algorithm Ed25519 -out key.pem
# TXT record on retyc.com:
echo "retyc.com. IN TXT \"v=MCPv1; k=ed25519; p=$(openssl pkey -in key.pem -pubout -outform DER | tail -c 32 | base64)\""
# GitHub secret MCP_PRIVATE_KEY of retyc/retyc-cli:
openssl pkey -in key.pem -noout -text | grep -A3 "priv:" | tail -n +2 | tr -d ' :\n'
```

Then delete `key.pem`, or keep it in a password manager.
